# Week 7 – DevOps, Docker, and Generative AI

This week focuses on practical delivery skills for modern software teams:

- DevOps and Agile collaboration practices
- Docker containerization and Compose-based setups
- Generative AI fundamentals and prompt-based experimentation

## Weekly tasks

1. DevOps and Agile
   - Review the Agile Manifesto, Scrum roles, ceremonies, and sprint planning concepts.
   - Complete the three module deliverables in the DevOps folder.

2. Docker
   - Practice common Docker commands and container lifecycle workflows.
   - Run the Compose-based example and document what each service does.

3. Generative AI
   - Explore LLM concepts, prompt engineering, and responsible AI usage.
   - Record one practical AI use case and one limitation or ethical concern.

## Folders

- **DevOps/** - Agile, Scrum, estimation, and user-story practice
- **Docker/** - Docker commands, concepts, and Compose examples
- **GenAI-Fundamentals/** - Generative AI concepts and starter exercises
