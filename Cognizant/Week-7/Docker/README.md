# Docker & Containerization Tasks

## Topics covered
- Docker basics and images
- Containers, volumes, and networking
- Docker Compose and multi-service setups
- Container orchestration concepts

## Hands-on tasks

1. Verify Docker is installed and running.
2. Pull and run a sample container such as nginx or alpine.
3. Practice basic commands for listing, stopping, and removing containers.
4. Review the Compose example and run the stack locally.
5. Document one difference between a volume and a bind mount.

## Deliverables

- Review the cheat sheet in the module folder.
- Run the example compose stack from the Docker module subfolder.
- Add one note about why container orchestration matters in production.
