# Using EF Core CLI to Create and Apply Migrations

This lab demonstrates how to create and apply database migrations using Entity Framework Core CLI.

## Files

- MigrationCommands.txt

## Concepts Practiced

- EF Core CLI
- Database Migrations
- Schema Updates
- Migration Management

## Commands Used

- dotnet ef migrations add
- dotnet ef database update
- dotnet ef migrations remove

## Purpose

Migrations help keep the database schema synchronized with changes made to entity classes.
