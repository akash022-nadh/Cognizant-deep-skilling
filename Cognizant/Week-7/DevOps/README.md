# DevOps and Agile Practice Tasks

Complete the following deliverables to strengthen your understanding of modern delivery practices.

## Task list

1. Study the Agile mindset and Scrum workflow.
2. Practice estimating work and planning a sprint.
3. Write clear user stories with acceptance criteria.

## Deliverables

| File | Covers |
|---|---|
| `AGILE-AND-SCRUM.md` | Agile Manifesto, Agile vs. Waterfall, Scrum roles, ceremonies, artifacts, and Definition of Done |
| `ESTIMATION-AND-SPRINT-PLANNING.md` | Story points, Planning Poker, sprint planning, velocity, and burndown interpretation |
| `USER-STORIES-AND-ACCEPTANCE-CRITERIA.md` | User story format, INVEST, and Given-When-Then acceptance criteria examples |

## Submission checklist

- Summarize one key Agile principle in your own words.
- Create one sprint backlog example with 3–5 items.
- Write one user story and its acceptance criteria.
