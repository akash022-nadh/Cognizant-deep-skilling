# Generative AI Fundamentals Tasks

## Topics covered
- Introduction to AI and machine learning
- Generative AI concepts
- Large language models and prompt engineering
- Real-world use cases and responsible AI

## Hands-on tasks

1. Learn the difference between traditional AI and generative AI.
2. Compare 2–3 prompts and observe how wording changes the result.
3. Document one business use case for LLMs in software development.
4. Note one ethical or safety concern when using generative AI.

## Deliverables

- Add a short summary of how LLMs work in simple terms.
- Include one prompt example and its result.
- Write a short reflection on responsible AI practices.
